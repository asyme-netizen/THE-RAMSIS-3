# THE RAMSIS

Static editorial website inspired by a luxury newspaper layout.

## Structure
- index.html -> hero article homepage
- pages/ -> section pages and archive/about
- assets/css/styles.css -> shared styling
- assets/js/main.js -> small shared behavior
- components/ -> saved header/footer partials for reference

## Hosting
Upload the full folder to any static hosting service.
Works on simple hosts because it is pure HTML/CSS/JS.
